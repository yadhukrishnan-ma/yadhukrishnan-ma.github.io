## ⚡ Executive Summary

**"From Stone to Silicon"** is a next-generation interactive 3D digital experience that guides visitors through the continuous march of human ingenuity across **16 technological eras**—from the prehistoric discovery of fire to modern autonomous humanoids and embodied robotics. 

Transitioning seamlessly from Era 16 into Yadhukrishnan MA's personal engineering laboratory, recruiters and engineers can inspect real-time 3D robot kinematics, interact with a live sub-millisecond Nav2 costmap planner, explore synchronized spatial teleoperation cockpits, and review 12 verified production robotics case studies.

## 🤖 Part II: The Robotics Engineering Portfolio

### 01 // Command Center & 3D Holographic ID Card
* **Interactive 3D Security ID Card:** Realistic cursor-following 3D perspective tilt (`rotateX`, `rotateY`) and 3D card-flip interaction displaying verified security clearances, iHub Robotics role, system diagnostics, and real-time firmware uptime.
* **Recruiter Fast-Track:** One-click access to the 30-Second Executive Dossier and direct verified PDF resume download.

### 02 // 3D Humanoid Inspection Bay
* **High-Precision WebGL Stage:** Rigged 67-joint humanoid model (`Xbot.glb`) with circular metallic podium.
* **8,000-Point Spatial LiDAR Cloud:** Rotating cyan distance rings representing live sensor point-cloud returns.
* **Kinematic Controls:**
  * `[ 360° Auto-Orbit ]`: Continuous orbital rotation with live azimuth degree readout.
  * `[ ⚡ X-Ray Mode ]`: Real-time WebGL wireframe shader reveal.
  * `[ ▶ Kinematic Walk Cycle ]`: Smooth animation crossfading between idle and walking clips.
  * `[ ↺ Reset Angle ]`: Smooth reset to default camera orientation.
  * **Cursor Gaze Tracking:** Damped head and neck bone tracking following visitor pointer coordinates.

### 03 // Spatial VR & Leader-Follower Teleoperation Cockpit
* **Multi-Viewport Feed:** 3 synchronized 60 FPS synthetic vision streams (World Camera, Left Wrist End-Effector, Right Wrist Manipulation Perspective).
* **Dual-Arm Joint Telemetry Table:** Real-time synchronized readouts for 14 kinematic joints (7 Left Arm + 7 Right Arm: Base Yaw, Shoulder Pitch, Elbow Pitch, Wrist Roll, Wrist Pitch, Wrist Yaw, Gripper Linear) with Leader vs Follower position bars ($Δ < 0.03\text{ rad}$ nominal green state).

### 04 // Interactive Nav2 Simulation Arena
* **Costmap Inflation Engine:** Dynamic radial cost gradient surrounding obstacles.
* **Interactive Controls:**
  * **Set Goal:** Click anywhere on the simulation arena to dispatch new goal coordinates and watch real-time A* path generation.
  * **Draw Obstacles:** Hold Shift and drag cursor across the arena to place custom dynamic obstacles that trigger instant obstacle inflation and dynamic path replanning.
  * **Clear Obstacles:** Reset the costmap arena to default testbed geometry.
* **Autonomous Pure Pursuit Rover:** Closed-loop movement with live sweeping 360° LiDAR rays.
